## Selected work

- **[Better Reader](https://github.com/UmarKhan19/better-reader).** A PDF library and reader that saves reading progress in the browser and stores files on disk. Includes local passage indexing and bounded retrieval.
- **[Agent Discussion Room](https://github.com/UmarKhan19/agent-discussion-room).** Runs multi-agent discussions with server-owned state, transactional persistence, and attempt leases. Recovers interrupted turns.
- **[Prompt Writer](https://github.com/UmarKhan19/prompt-writer).** Turns vague requests into structured prompts using TypeScript and Mastra. Includes scripted conversation scenarios and scoring. The hosted interface is Mastra Studio.
